## About

**Mugen Art Lab** is an independent personal project focused on creating practical tools for streaming, audio, media processing, and creative workflows.

These tools began as solutions to real problems in my own setup and are shared publicly in the hope that they may help others too.

## Projects

### [Mugen Gamepad Overlay](https://github.com/Mugen-Art-Lab/Mugen-Gamepad-Overlay)

A native local gamepad overlay source for OBS Studio on Windows.

Renders controller input directly inside OBS Studio without a browser source, website, WebSocket server, or network input relay. Supports a built-in universal skin, Input Overlay 5.x presets, and local GamepadViewer skins.

**Public release available:**

[Download the latest version](https://github.com/Mugen-Art-Lab/Mugen-Gamepad-Overlay/releases/latest) · [View documentation and source code](https://github.com/Mugen-Art-Lab/Mugen-Gamepad-Overlay)

### [Mugen Deej](https://github.com/Mugen-Art-Lab/Mugen-Deej)

A portable bilingual Windows client for deej-compatible USB audio controllers.

**Public release available:**  
[Download the latest version](https://github.com/Mugen-Art-Lab/Mugen-Deej/releases/latest) · [View documentation and source code](https://github.com/Mugen-Art-Lab/Mugen-Deej)
